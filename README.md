# Near-Accident Driver

Investigation of near-accident car-driving scenarios using Deep Imitation Learning + Reinforcement Learning.

## Overview

This project investigates how a driving agent behaves in near-accident scenarios — situations where a collision is narrowly avoided — by combining imitation learning (learning from expert/human driving demonstrations) with reinforcement learning (optimizing driving behavior through reward-based feedback). The goal is to better understand and model how agents can learn safe recovery behavior in high-risk driving moments.
